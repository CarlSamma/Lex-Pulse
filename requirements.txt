# LexPulse · Legal Intelligence Agent (Hackathon per Giuristi · Traccia 2)
# Nota tecnica: il progetto è basato su Node.js + TypeScript (React + Express),
# pertanto il file principale per l'installazione dei pacchetti è package.json (`npm install`).
# Questo file riepiloga tutti i requisiti di sistema, le dipendenze e le variabili d'ambiente.

# === 1. RUNTIME E STRUMENTI DI SISTEMA ===
# Node.js >= 20.x (consigliato 22.x LTS)
# npm >= 10.x

# === 2. VARIABILI D'AMBIENTE (Settings > Secrets) ===
# OPENROUTER_API_KEY   -> Chiave API OpenRouter per i 6 modelli LLM:
#                         - anthropic/claude-sonnet-5.5
#                         - openai/gpt-6.1-terra
#                         - google/gemini-4-hydrogen
#                         - deepseek/deepseek-v4-pro
#                         - mistralai/mistral-large-4-0
#                         - meta-llama/llama-4-maverick
# GEMINI_API_KEY       -> Opzionale (fallback server-side per google/gemini-4-hydrogen)
# APP_URL              -> URL pubblico dell'applicazione
